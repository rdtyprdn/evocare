# evocare
EvoCare adalah platform SaaS &amp; CMS pengabdian masyarakat. Menghubungkan LSM, komunitas, instansi, relawan, dan donatur dalam aksi sosial (pendidikan, kesehatan, bencana). Dilengkapi fitur pencarian cerdas berbasis lokasi, kategori isu, dan jadwal dinamis untuk pendaftaran terpusat yang mudah, terstruktur, dan transparan.
