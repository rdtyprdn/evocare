# evocare
EvoCare (Event of Care) merupakan Platform Software as a Service (SaaS) dan Sistem Konten Manajemen yang dirancang sebagai ekosistem digital untuk memfasilitasi dan mengelola berbagai program pengabdian masyarakat. Platform ini mencakup inisiatif aksi sosial yang luas, meliputi bidang pendidikan, kesehatan, pelestarian lingkungan, pemberdayaan ekonomi, hingga darurat bencana. Sistem ini bertujuan sebagai jembatan penyelenggaraan kegiatan seperti Lembaga Swadaya Masyarakat, Komunitas, Institusi Pendidikan dan Masyarakat yang ingin berkontribusi sebagai relawan, donatur maupun pihak penerima layanan. Pengguna dapat dengan mudah mengeksplorasi peluang partisipasi sosial sesuai dengan minat, kapasitas dan wilayah tempat tinggal mereka. Sistem ini dilengkapi dengan mesin pencarian dan filtering cerdas. Dalam platform ini dapat memungkinkan pengguna untuk mengeksplorasi inisiatif sosial melalui fitur lokasi, filter jadwal dinamis dan kategori isu. Seluruh fitur ini bermuara pada satu proses pendaftaran terpusat dengan menjadikan keterlibatan masyarakat dalam kegiatan sosial jauh menjadi lebih mudah untuk diakses, terstruktur dan transparan.
